# Organizador-de-Imposto-de-Renda
Planilha para organizar seu imposto de renda
Nele podemos preencher todas as informações necessárias para enviar para o contador fazer a declaração ou fazer nós mesmos
Primeira aba preenchemos nossas informações pessoais
Segunda aba para preencher as informações das contas bancárias e com um gráfico mostrando quanto temos disponível atualmente em cada banco
Terceira aba devemos preencher nossos ganhos mês a mês.
